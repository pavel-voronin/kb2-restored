# Кандидаты на ошибки

Это список подозрительных мест, найденных при чтении кода. Они не исправлены. Наличие строки здесь ещё не означает, что проблема достижима в обычной игре: для каждого пункта предстоят воспроизведение, проверка причины и согласование исправления. Демонстрации в вебе будут отдельной работой.

| ID | Место | Подозрение | Что проверить позже |
| --- | --- | --- | --- |
| B001 | `SRC/KBCAL.PAS`, `EndWeek` | При `Gold = Payroll` выход `Gold > Payroll` не наступает, а ветка `Payroll > Gold` не меняет состояние. | Нулевая казна без армии и точное равенство денег недельным расходам. |
| B002 | `SRC/KBCAL.PAS`, `LoseEmptyCastles` | Перебор идёт по `Island`, а плитка меняется в `Game.Campaign.Map[Game.Campaign.Island, ...]`. | Потеря пустого замка на другом острове; сравнить карты обоих островов. |
| B003 | `SRC/KBVISIT.PAS`, `FindWanderingArmy` | Поиск не ограничен индексом 20 и не имеет результата «не найдено». | Можно ли получить плитку армии без соответствующей записи обычными действиями. |
| B004 | `SRC/KBSAVE.PAS`, `ReadCampaign` | Размер файла используется для чтения в буфер без проверки вместимости; распаковка рассчитана на фиксированный объём. | Короткое, обрезанное и слишком большое сохранение; определить конкретную область повреждения. |
| B005 | `SRC/KBFILES.PAS`, `SRC/KBSAVE.PAS` | Результаты DOS-вызовов открытия, чтения, создания и записи проверяются не полностью. | Нет ресурса, нет прав записи, заполненный диск, короткое чтение; отдельно проверить сообщения и состояние кампании. |
| B006 | `SRC/KBLOAD.PAS`, `PrepareLoadedCampaign` | Для всех плиток 9 используется растущий `Count`, а `Positions` вмещает две позиции. | Действительно ли корректная кампания гарантирует не более двух таких плиток; при избытке установить, что перезаписывается. |
| B007 | `SRC/KBSTART.PAS`, `StartupMenu.EnumerateFiles` | После `FindFirst` отсутствие файлов распознаётся только по коду 2. Другие ошибки проходят к использованию `SearchRec.Name`. | Какой код возвращает конкретный DOS при отсутствии `*.KB2`; проверить пустую папку и ошибки поиска. |
| B008 | `SRC/KBBATTLE.PAS`, `Battle` | `FillChar(Combat.Enemy, 10, 100)` и аналогичный вызов для игрока заполняют 10 байт, а не десять записей. Остальное состояние инициализируется по отдельности. | Есть ли чтение оставшихся неинициализированных полей; сам короткий `FillChar` ещё не доказывает наблюдаемый баг. |
| B009 | `SRC/KBBMAGIC.PAS`, `SelectSpellTarget.ResurrectUnit` | `NewHitPoints` уже включает прежние HP, а количество затем складывается с `BattleDistances`. Возможен повторный учёт живых воинов. | Сопоставить HP, число воинов и предел `InitialCount` до/после воскрешения на нескольких частично повреждённых отрядах. |
| B010 | Подключаемый `Crt` из `PASCAL/TURBO.TPL`; запуск измерительных сборок | При дополнительном запуске `REFCNT` и `CURCNT` на `core=dynamic / cycles=max` получен `Runtime error 200` до появления CSV. Возможна проблема калибровки задержек CRT; причина не локализована. На фиксированных 3000 и 700 cycles серии проходят. | Повторить на обычных EXE обеих веток при заданных высоких скоростях, найти место деления и установить границу воспроизведения. До этого не считать доказанным багом игрового кода. |

Для будущего разбора сохраняем отдельно: начальное состояние, последовательность действий, исходный результат, ожидаемое правило и результат исправления. Изменения баланса не считаем исправлением ошибки без отдельного решения.
