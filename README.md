# King's Bounty 2 — 100% реконструкция исходного кода

![Скриншот King's Bounty 2](screenshot.png)

Полная реконструкция DOS-игры на Turbo Pascal 7.0: код, графика, шрифт и инструменты сборки ресурсов. Весь проект собирается средствами начала 1990-х — DOS, Turbo Pascal 7,0, PCX и CP866.

Собранные EXE, ресурсы и документы совпадают [с оригиналом](https://archive.org/details/msdos_Kings_Bounty_2_1993) побайтово: **23 файла, 920 352 байта**.

Оригинальную игру разработал **Сергей Прокофьев**.

## Собрать и запустить

Скопируйте папку проекта в DOS и выполните из её корня:

```dos
BUILD
RUN
```

Готовая игра появляется в `SRC/DIST/`.

На современном компьютере откройте DOSBox и подключите папку проекта как диск:

```dos
MOUNT C C:\GAMES\KB2
C:
BUILD
RUN
```

Замените `C:\GAMES\KB2` на путь к своей копии проекта.

## Детали

Имена файлов и группировка кода выбраны при реконструкции: исходное разбиение кода можно узнать только у автора. Начните с `SRC/KB2.PAS`; [карта модулей](SRC/README.TXT) описывает остальные части игры.

PCX-экраны имеют размер **640×350**. Атласы состоят из кадров **96×60**, по четыре в строке; `FONT.PCX` содержит 240 знаков **8×8**. При редактировании сохраняйте размеры, 16-цветную палитру EGA и четыре битовые плоскости PCX.

Тексты и Pascal-исходники сохраняйте в **CP866 с CRLF**; имена файлов соответствуют **DOS 8.3**.

Неустановленные области обозначены `Unknown_*`; их размеры и порядок сохраняются при компиляции.

Оригинальные файлы игры взяты из [Internet Archive](https://archive.org/details/msdos_Kings_Bounty_2_1993).
